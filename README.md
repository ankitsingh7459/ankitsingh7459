# 🚀 Featured Project

## 🖨️ PrintAPM

> A self-service campus printing platform built to make document printing faster and easier for students.

### How it works

```text
Upload Document
       ↓
Choose Print Settings
       ↓
Make Payment
       ↓
Receive 4-Digit Code
       ↓
Enter Code at Kiosk
       ↓
Document Prints Automatically
```

### 👨‍💻 My Role

**Co-Founder & Technical Lead**

I work on:

- Full-stack development
- Backend API design
- Database architecture
- Authentication & OTP systems
- Payment integration
- Windows kiosk application
